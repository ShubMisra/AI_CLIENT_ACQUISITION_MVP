# Public work sample: CRM lead-quality automation

**Demonstrated:** Local Python pipeline checks 16 fictional leads, retains every record, detects exact duplicates, escalates ambiguous names/company matches, tags interest categories and generates review CSV/JSON and reconciliation report. Tests cover repeatability, unchanged input and no network use.

**Not demonstrated:** Actual client projects, live CRM sync, AI model classification, outreach or deployment. All records and emails are fabricated, using example.org only.

**Potential paid extension:** Scoped CRM API integrations, configurable business rules, protected audit trail, human-approved merges, evaluated classification and production operations.

Run: python app.py --input synthetic_leads.csv --output demo_output
